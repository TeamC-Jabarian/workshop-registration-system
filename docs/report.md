## 1. Introduction

The Workshop Registration System is designed
to simplify the management of educational
workshops and student registrations.

The system helps students register for workshops
and allows the education administrator to manage
workshops and monitor participant capacity.

## 2. Project Objectives

- Simplify workshop registration.
- Manage workshop information.
- Prevent duplicate registrations.
- Control workshop capacity.
- Allow registration cancellation.
- Generate participant reports.

## 3. Main System Features

1. Create and manage workshops.
2. Register students in workshops.
3. Prevent duplicate registrations.
4. Prevent registrations beyond capacity.
5. Cancel student registrations.
6. Display participant lists and registration counts.
